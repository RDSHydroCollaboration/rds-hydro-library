# rds-hydro-library

Open, bilingual (NO/EN) type library and power-plant template for the Norwegian hydropower sector. Contains codes and preferred terms only.

- `data/types.csv`: type table (`label_no`, `label_en`, optional `label_xx`)
- `data/plant_template.json`: plant template (mind map on the site)
- `site/`: static site (GitHub Pages) with NO/EN toggle, search and csv/xlsx/json download

See `CONTRIBUTING.md` and `NOTICE.md`. Data CC-BY-4.0, code MIT.
